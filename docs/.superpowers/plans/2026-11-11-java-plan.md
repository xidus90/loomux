# Java im Code-Graphen, in der Prüfkette und in der Kompatibilitätsliste — Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Java steht in Graph, Prüfkette und Kompatibilitätsliste auf der Stufe von Python, für Temurin 8, 11, 17, 21, 25 und 27.

**Architecture:**
- Extraktor `java` und Resolver `resolve/java.go` nach dem Muster von C#. Java hat ein Paket je Datei, also `Result.Package` statt `Enclosing`.
- Stack `java` mit den Varianten `maven` und `gradle`.
- Laufzeit `java` im Compat mit Adoptium als Release-Quelle.

**Tech Stack:** Go, gotreesitter v0.57.0 (`grammars/java`), Maven 3.10.0, Gradle 9.9.1, JUnit 5.14.4 und 6.1.3, JaCoCo 0.8.16, Checkstyle 9.3, 12.x und 14.4.0.

**Spec:** `docs/.superpowers/specs/2026-11-11-java-design.md` (Pins: `2026-11-10-graph-sprachen-recherche.md`, Nachtrag 2026-11-11)

## Review Focus

1. **Gleicher einfacher Typname in zwei Paketen, beide per `*` importiert.**
   Ergebnis `ReasonAmbiguous`, keine falsche Kante. Test in Task 2.
2. **Verschachtelter Typ, der eine Methode des äußeren Typs ruft.** Die
   Kante führt auf die äußere Methode. Test in Task 2.
3. **Datei ohne `package`-Deklaration neben Dateien mit Paket.** Sie
   bildet das Paket `""`. Test in Task 2.
4. **Repo mit `pom.xml` und `build.gradle`.** Maven gewinnt, mit Hinweis.
   Test in Task 3.
5. **Java-25-Lücken** (`import module`, Anweisung vor `super(...)`). Der
   Rest der Datei kommt an. Test in Task 1.
